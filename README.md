# 🐿️ Белочка спасает мир — 2D-платформер на raylib (C++)

Курсовой проект по специальности «Разработка и сопровождение программного обеспечения информационных систем».

Двухмерный платформер про белку, которая защищает родной лес от чёрных лесорубов и вандалов: собирает орехи, преодолевает препятствия, тушит пожары и сражается с врагами.

## Возможности

- 5 уровней с собственными фонами, платформами, врагами и препятствиями;
- два типа врагов: дровосек (патрулирует землю) и вандал (летает);
- сбор орехов и магазин скинов (жёлтая, тёмная, белая, золотая белка);
- стены огня, которые можно потушить, нажав на кнопку;
- жизни, экран победы и поражения;
- сохранение прогресса в файл `squirrel_save.txt` (открытые уровни, орехи, скин);
- поддержка русского языка (загрузка кириллических символов из `arial.ttf`).

## Уровни

1. Лесная опушка
2. Тёмная роща
3. Заброшенная пилорама
4. Горящий лес
5. Лагерь вандалов

## Сборка из исходников

Требуется **Visual Studio 2022** с рабочей нагрузкой «Разработка классических приложений на C++».

1. Откройте `KRS.sln`.
2. Дождитесь восстановления NuGet-пакета `raylib 5.5.0` (или выполните «Восстановить пакеты NuGet»).
3. Выберите конфигурацию `Debug | x64` и нажмите **F5**.

> Файлы ресурсов (`image/`, `arial.ttf`, `NewProject.chm`) должны находиться в рабочей директории проекта — в корне репозитория.

## Установка готовой версии

Готовый установщик лежит в [`installer/BelkaSetup_v1.0.exe`](installer/BelkaSetup_v1.0.exe).

1. Скачайте файл и запустите его.
2. Следуйте инструкциям мастера установки.
3. Запустите игру ярлыком «Белочка спасает мир» на рабочем столе.

## Структура репозитория

```

KRS.vcxproj                      — файл проекта

Header.h                         — вспомогательные структуры/константы

LAB20_ОТЧЕТ.md                   — отчёт по ЛР №20 (Markdown)
```
